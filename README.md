# WaveletNF

This repo contains the official implementation for Wavelet-Enhanced Normalizing Flows. To run experiments, please see shell scripts in src/runners.

The data can be found at https://drive.google.com/drive/folders/1x2Hk4u_jrbbnJAIA5GDKXmuX456GMWQu?usp=sharing, although for additional dataset details please see the links below:

Datasets:
    - SMD: https://github.com/NetManAIOps/OmniAnomaly
    - PSM: https://github.com/eBay/RANSynCoders 
    - SWaT: https://itrust.sutd.edu.sg/itrust-labs_datasets/dataset_info/ 
    - WADI: https://itrust.sutd.edu.sg/itrust-labs_datasets/
